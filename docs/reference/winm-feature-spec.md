## 2. 컨텍스트 메뉴 (64개 항목)
파일/폴더 우클릭 메뉴. 새로 만들기(5종: 폴더/파일/바로가기 등), 복사·이동·삭제 확인
흐름(12개), 보기/편집(2개), 실행(10개: 연결 프로그램/파라미터 포함), 단축아이콘 만들기,
작업(6개: 즐겨찾기 등록 등), 필터(2개) 섹션으로 구성.

## 3. 툴바 (23개)
주요 파일 작업 + MCD/QCD/드라이브 바로가기 버튼. 도구 이름 표시 토글 가능.

## 4. 대화상자

### 4.1 압축하기
압축 파일명(N) · 경로(F10) · 압축 종류(T) · 압축 방법(M: 최고/보통/빠르게/가장 빠르게/저장) ·
분할 압축(V: 안함/1440KB/2880KB/10MB/20MB/50MB/100MB) · 암호 입력(P)+표시(W) ·
하위 폴더 포함(S) · 압축후 원본 삭제(D)

### 4.2 압축풀기
경로(E/F10) · 다음 파일만 풀기(S) · 암호(P)+표시(W) · 경로명도 함께 풀기(F) ·
덮어쓰기 정책: 모두 덮어쓰기(A)/예/모두/모두통과/통과/새파일만/취소 ·
분할 압축 볼륨 처리(다음 볼륨 디스크 교체 프롬프트) · 암호 걸린 항목 안내

### 4.3 파일 분할
저장할 경로(P) · 분할 크기(S: 자동/1400KB/2800KB/10MB/20MB/50MB/100MB/바이트 직접입력,
최소 100,000바이트) · 분할후 원본 삭제(D) · 배치파일 생성(B, ON=배치파일방식/OFF=RzJoin방식) ·
원본크기/분할크기/분할개수 정보 표시

### 4.4 이름 바꾸기 (일반/고급)
일반: 새 이름 직접 입력. 고급: 파일 이름 패턴(`<&N>` 이름, `<&C>` 번호, `<N#-#>` 범위,
`<&YMD>` 날짜, `<&hms>` 시간) + 확장자 패턴(`<&E>`) 조합. 확장자 변경안함(X) 옵션.

### 4.5 속성/날짜 바꾸기
현재 속성 표시(기록/읽기전용/숨김/시스템) → 새 속성 지정(회색=바꾸지 않음).
날짜/시간 변경 포함.

### 4.6 폴더 만들기
새 폴더 이름 입력 + 중복 검사.

### 4.7 환경 설정 (7개 탭)
- 파일창: 첫째/둘째 파일창 경로표시줄·헤더·상태표시줄, 컬럼 구성, 정렬
- 표시: 폰트/색상/줄간격 등 표시 요소
- 처리: 복사·이동·삭제 동작 옵션
- 색깔: 67개 항목 — 파일 종류별 색상 정의 (확장자/속성 기반)
- 압축파일: 압축 관련 기본값
- 프로그램: 시작 동작, 업데이트 주기(Update.INI: 2일)
- 기타: 나머지 옵션

## 5. 특수 UI

### MCD (폴더관리기, 16개)
드라이브 전체 폴더 트리. 빨리 찾기(이름 앞부분 일치로 점프), 작은 아이콘 토글,
트리 손상 시 전체 다시 읽기. 단축키: F2 새로고침, F3 드라이브, F4 이동, F5 복사,
F6 새이름, F7 새폴더, F8 삭제, F9 등록정보.

### QCD (즐겨찾기, 14개)
경로 북마크 목록. 내 문서/바탕화면/시작메뉴 기본 항목, 현재 폴더 추가,
경로 직접 입력(P), 설정.

### 드라이브 변경 (8개)
드라이브 목록 상자 (Change Drive).

### 파일창 설정 (43개)
컬럼/정렬/표시 등 파일 목록 패널 세부 설정.

## 6. 기타 기능
- descript.ion 주석: 주석 입력(S)/모두 삭제(E), 목록 표시
- 목록 만들기(I): 파일 목록 텍스트 생성 / 선택 항목만(L)
- 도스명령(N), 파라미터 입력 실행(P)
- WinM 업데이트: 도움말 메뉴에서 인터넷 경유 자동 업데이트 (2일 주기 확인)
- 프로그램 정보창(A): 버전 정보

## 2. 단계별 계획

**Phase A — 릴리즈 기반 (CI)**
- Linux arm64 빌드 추가 (현재 매트릭스에 없음 — ARM 러너 또는 크로스 컴파일)
- 4-target 릴리즈 파이프라인 검증

**Phase B — 기능 갭**
1. 자동 업데이트 (Tauri updater, 2일 주기 확인 로직)
2. 네트워크 드라이브 (Windows: WNet API / Linux: GVfs·SMB / macOS: NetFS)
3. 인쇄 (OS별 인쇄 대화상자 연동)
4. 도스명령/외부 명령어 패널 정리

**Phase C — 릴리즈**
- 버전 결정 (현 0.5.0), 릴리즈 노트, 에셋 큐레이션
- 4-target 빌드 → GitHub Release

## 3. 타겟별 주의사항
- **공통**: Tauri 2가 4개 타겟을 네이티브 지원하므로 아키텍처 이슈 없음
- **Linux arm64**: CI 매트릭스 추가로 해결
- **macOS arm64**: Gatekeeper/quarantine 안내 유지 (README에 문서화됨)
- **Windows 11 x64**: WebView2 동봉 (Win11 기본 포함)
