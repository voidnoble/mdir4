# Mdir4 v1.0.0 릴리스 노트

**릴리스일:** 2026-09-26
**버전:** 1.0.0 (P6 완료)

WinM 4.5의 듀얼 패널 UX를 계승한 크로스플랫폼 파일 관리자 Mdir4의 첫 정식 버전입니다.
Tauri 2 + Rust + React + TypeScript 스택으로 Windows/macOS/Linux를 지원합니다.

## P6에서 추가된 기능

### 보기 · 정렬 · 필터
- 컬럼 헤더 클릭으로 정렬 (이름/크기/날짜, 오름차순/내림차순 토글, 폴더 우선)
- 와일드카드 필터 (`*`, `?` 지원, `;`로 다중 패턴) — `F` 키
- 경로 히스토리 — `Alt+Left`/`Alt+Right`로 뒤로/앞으로 이동

### 선택
- 선택 반전 — `V` 또는 `Ctrl+I`
- 패턴으로 선택/해제 — `N` / `Shift+N`

### 속성 · 설명 · 목록
- 속성 다이얼로그 — `Alt+Enter`
  - 파일/폴더 속성, 폴더 용량(재귀 계산), 읽기 전용 토글, 수정 날짜 변경
  - `descript.ion` 파일 설명 읽기/쓰기 (WinM 호환)
- 파일 목록 생성 — `L` 키로 TXT/CSV 저장 (`mdir4-list.txt`/`mdir4-list.csv`)

### 연결 프로그램 · 외부 압축기
- 파일 열기 — `O` 키: 확장자 연결 설정 또는 시스템 기본 프로그램으로 실행
- 환경설정에서 확장자별 연결 프로그램 관리
- 외부 압축기/해제기 명령 설정 (예: `7z a`, `rar x`) 후 압축 다이얼로그에서 실행

### 도움말
- `F1` 키로 전체 단축키 도움말

## 전체 단축키 (v1.0.0)

| 키 | 동작 | 키 | 동작 |
|---|---|---|---|
| F1 | 도움말 | F2 | 새로고침 |
| F5 | 복사 | F6 | 이름바꾸기 |
| F7 | 폴더 만들기 | F8/Delete | 삭제 |
| F10 | MCD (트리) | F11 | QCD (즐겨찾기) |
| F12 | 환경설정 | Tab | 패널 전환 |
| Space/Insert | 선택 | Ctrl+A | 전체 선택 |
| Alt+Enter | 속성 | Alt+Left/Right | 뒤로/앞으로 |
| C/M/D/R/K/Z/U | 복사/이동/삭제/이름바꾸기/폴더만들기/숨김/전체선택 | A | 압축 |
| S | 분할/결합 | O | 연결 프로그램으로 열기 |
| F | 필터 | V | 선택 반전 |
| N / Shift+N | 패턴 선택/해제 | L | 파일 목록 생성 |
